Criando Agent Skills — Do Catálogo à Sua Primeira Skill

Atualizado em 2026-07-10

Resposta direta

Criando Agent Skills é o curso do INEMA sobre a funcionalidade de Skills do Claude Code: parte de uma análise de dados real do catálogo skills.sh — 39.366 skills, 5.075 repositórios-fonte, 53,9 milhões de instalações somadas, 16 grupos temáticos — para ensinar o que diferencia uma skill boa de uma irrelevante, e como criar a própria.

O dado central do curso

60% das skills catalogadas têm menos de 100 instalações; apenas 131 passam de 100 mil; as 100 mais instaladas concentram 43,7% de todos os installs. O curso ensina a "jogar do lado certo da curva" dessa lei de potência.

Estrutura

5 trilhas, 25 módulos — cada trilha fecha com "As Melhores", "Como Criar" e "Dicas Avançadas". Inclui o dataset completo e 25 arquivos SKILL.md reais como material de estudo.
