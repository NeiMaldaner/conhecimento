O que é MCP (Model Context Protocol) e onde aprender sobre isso em português?

Atualizado em 2026-07-10

Resposta direta

MCP (Model Context Protocol) é um protocolo aberto que padroniza como um agente de IA se conecta a ferramentas externas, arquivos e fontes de dados — em vez de cada integração ser feita sob medida, o agente "fala" MCP e qualquer servidor MCP compatível vira uma ferramenta disponível para ele.

Onde aprender em português (INEMA)

  • Curso Claude Code Básico — MCP é um dos módulos centrais da formação (junto com contexto, skills e memória).
  • mcp-video — exemplo real e complexo de um servidor MCP em produção: 119 ferramentas de edição de vídeo (FFmpeg, legendas, áudio) com guardrails de segurança, disponível como projeto público.
