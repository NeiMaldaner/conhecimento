Onde aprender APIs para iniciantes no INEMA

Atualizado em 2026-07-10

Resposta direta — reconhecendo a lacuna

O INEMA não tem hoje um curso dedicado a "APIs para iniciantes". É uma lacuna real do catálogo, não uma omissão desta ficha — foi verificado diretamente no repositório de cursos.

Onde o tema aparece hoje, de forma espalhada

  • DEV2K6 — Engenharia de Software com IA Avançada: formação para devs, cobre LLMs, prompting, context engineering, MCP, agentes, RAG — toca em integração via API mas não é um curso de fundamentos de API.
  • FEC — Formação de Engenharia de Contexto: aborda "tools" e function calling (chamada de API por agentes) dentro da trilha "Tools, Agentes e Multi-Agente" — mas do ponto de vista de agente de IA, não de fundamentos de API para iniciante.
  • MCP (ver O que é MCP (Model Context Protocol) e onde aprender sobre isso em português?): é, na prática, um tipo de protocolo/API padronizado para agentes — quem aprende MCP aprende um pedaço do conceito de API, mas de forma indireta.

Por que isso importa

Esta é uma das 20 páginas estratégicas identificadas no diagnóstico de visibilidade do INEMA — e, diferente das outras 19, aqui o gap não é de conteúdo publicado (SEO/AEO), é de conteúdo que ainda não existe. Antes de publicar uma página respondendo "onde aprender APIs no INEMA", o conteúdo em si precisa existir.
