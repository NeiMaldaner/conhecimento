Conhecimento / Pergunta frequente

Onde aprender a usar o terminal e ferramentas como Claude Code e Codex?

Atualizado em 2026-07-10

Resposta direta

Três cursos do INEMA cobrem exatamente isso, em ordem recomendada para quem começa do zero:

  1. Do Zero ao Deploy — para quem nunca usou terminal: usar o terminal, Git, GitHub Pages, deploy na Vercel, Docker. Sem pré-requisitos.
  2. Claude Code Básico — curso completo do agente de codificação da Anthropic (6 trilhas, 125 tópicos): instalação, comandos, contexto, skills/memória, MCP, multiagentes.
  3. Codex Básico — curso completo do agente de codificação da OpenAI (6 trilhas, 46 módulos): instalação, terminal, Agent Builder, BMAD, equipe de agentes.
