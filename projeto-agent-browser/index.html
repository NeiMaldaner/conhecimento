agent-browser — CLI de automação de navegador para agentes de IA

Atualizado em 2026-07-10

Resposta direta

agent-browser é uma CLI de automação de navegador headless projetada para uso por agentes de IA — escrita em Rust, com um fallback em Node.js. Permite que um agente controle um navegador programaticamente (abrir páginas, clicar, extrair conteúdo).

Contexto de uso

Usada por outros fluxos de trabalho do ecossistema INEMA que precisam de acesso à web por agentes (ex.: extração de conteúdo de páginas logadas — ver ~/.claude/CLAUDE.md, seção sobre acesso a áreas logadas via agent-browser).

Origem e natureza do projeto

Como a maioria dos projetos do ecossistema INEMA, nasceu de uma live ou imersão prática do Nei — é open source e público, compartilhado com a comunidade, não é produto vendido nem trabalho de implementação para cliente (ver O que é gratuito e o que é pago no INEMA).
