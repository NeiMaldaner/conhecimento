claude-seo — skill de SEO e otimização para busca por IA (GEO)

Atualizado em 2026-07-10

Resposta direta

claude-seo é uma skill do Claude Code que automatiza auditoria de SEO técnico e on-page, schema markup, geração de sitemap, e — de forma notável — otimização para busca por IA (GEO, Generative Engine Optimization).

Por que é relevante para o programa AIV

Este projeto é evidência direta de que o INEMA já cura/produz ferramentas na própria área de AEO/GEO — reforça a autoridade do INEMA no tema quando a F2 publicar (ver Case (em construção): o INEMA aplicando AEO/GEO em si mesmo — programa AIV).

Origem e natureza do projeto

Como a maioria dos projetos do ecossistema INEMA, nasceu de uma live ou imersão prática do Nei — é open source e público, compartilhado com a comunidade (ver O que é gratuito e o que é pago no INEMA — o INEMA cura e ensina, não vende implementação sob contrato).
