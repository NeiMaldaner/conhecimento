inemaimg — servidor local multi-modelo de geração/edição de imagens

Atualizado em 2026-07-10

Resposta direta

inemaimg é um servidor local de geração e edição de imagens com IA, com hot-swap (troca a quente, sem reiniciar) entre três modelos: Qwen-Edit, FLUX.2 e ERNIE.

Nota de convenção do usuário

O modelo de imagem padrão do ecossistema INEMA para geração é o flux2-klein (ver regra global do Nei); inemaimg parece ser a infraestrutura de servidor que hospeda esse e outros modelos localmente — relação exata entre os dois ainda não confirmada.

Origem e natureza do projeto

Como a maioria dos projetos do ecossistema INEMA, nasceu de uma live ou imersão prática do Nei — é open source e público, compartilhado com a comunidade (ver O que é gratuito e o que é pago no INEMA).
