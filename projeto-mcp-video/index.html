mcp-video — servidor MCP de edição de vídeo para agentes de IA

Atualizado em 2026-07-10

Resposta direta

mcp-video é um servidor MCP (Model Context Protocol) especializado em edição de vídeo, feito para ser usado por agentes de IA com guardrails de segurança — 119 ferramentas cobrindo FFmpeg, legendas, áudio, efeitos visuais, integração com o HyperFrames (editor do próprio ecossistema INEMA) e validação preflight (checagens antes de executar operações).

Por que é relevante

Bom exemplo concreto para a ficha O que é MCP (Model Context Protocol) e onde aprender sobre isso em português? — mostra MCP aplicado num caso real e complexo, não só teoria.

Origem e natureza do projeto

Como a maioria dos projetos do ecossistema INEMA, nasceu de uma live ou imersão prática do Nei — é open source e público, compartilhado com a comunidade (ver O que é gratuito e o que é pago no INEMA).
