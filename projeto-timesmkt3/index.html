timesmkt3 — fábrica de conteúdo de marketing com agentes de IA

Atualizado em 2026-07-10

Resposta direta

timesmkt3 é uma "fábrica de conteúdo de marketing": um sistema de agentes de IA orquestrados via bot de Telegram que automatiza a produção de conteúdo de marketing.

Família de projetos relacionados — atenção à ambiguidade de nome

O ecossistema tem uma família de projetos de marketing com agentes, nomeados de forma próxima e potencialmente sobreposta: timesmkt (GitHub: "Sistema de agentes de IA via Claude Code que pesquisa, cria textos, gera imagens e vídeos para campanhas de marketing"), timesmkt2 (GitHub: "ITAGMKT — pipeline de agentes de IA para marketing digital via bot Telegram"), timesmkt3 (esta ficha) e imkt4 (GitHub, descrição menciona explicitamente "timesmkt3: pipeline de agentes de IA..."). Não está claro pelas fontes disponíveis qual é a versão atual/recomendada.
