VideosDGX — 4 Video LLMs em Docker no NVIDIA DGX Spark

Atualizado em 2026-07-10

Resposta direta

VideosDGX é um setup Docker multi-container que disponibiliza 4 modelos de geração de vídeo por IA — LTX-2, Wan 2.1, MAGI-1 e Waver — rodando no hardware NVIDIA DGX Spark.

Projeto irmão — atenção à ambiguidade de nome

Existe VideosDGX2 (repositório GitHub separado: "Stack de geração de vídeo com Wan 2.2 + ComfyUI rodando local no NVIDIA DGX Spark, com interface web e fila de jobs") — parece ser uma segunda geração/versão do mesmo conceito, com modelo diferente (Wan 2.2 + ComfyUI vs. os 4 modelos do VideosDGX original).
