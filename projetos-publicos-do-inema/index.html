Projetos públicos do INEMA

Atualizado em 2026-07-10

Resposta direta

O INEMA publica dezenas de projetos abertos — a maioria em github.com/inematds, muitos com uma página de guia em GitHub Pages (inematds.github.io/<projeto>). Cobrem principalmente: agentes de IA e automação, geração/edição de vídeo e imagem, ferramentas para o Claude Code (skills), plataformas educacionais e utilitários diversos.
